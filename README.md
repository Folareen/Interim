# Interim

An AI agent that keeps you looking like yourself while your hair, skin and body change. Built for the YouCam API Skin AI and eCommerce VTO Hackathon.

TypeScript monorepo: Next.js PWA (`apps/web`), NestJS API and worker (`apps/api`), MCP server (`apps/mcp`), shared packages in `packages/`.

```bash
pnpm install && cp .env.example .env && docker compose up -d && pnpm dev
```

Docs start at [docs/README.md](docs/README.md). Setup details: [docs/development.md](docs/development.md).
