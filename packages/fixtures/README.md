# fixtures

Recorded YouCam responses (secrets removed) and sample profiles. Written by `YOUCAM_MODE=record`, read by `YOUCAM_MODE=replay`. See docs/integrations/youcam.md.

YouCam fixtures are `youcam/<tool>/<fixtureKey>.json`: the final status response of one task, with the query string cut from signed links. `fixtureKey` is the call_cache key.
